课堂演示动画

这些动画用来回答同学们最常问的一句话——“文件之间的调用关系连不起来”：一张图看运行期真实发生的调用链，一段动画看源码文件怎样被编译、链接成一个程序。

Call Graph · 可播放 启动调用链 从 QEMU 加载 ELF、跳到 _start，到 kernel_main 调用 printk / memset / memcpy / strlen 的完整运行期调用图；点按钮可播放一个圆点按真实顺序走一遍。 Build Pipeline 构建流水线动画 源码文件在哪个目录、怎样经 make clean / make / make run 被编译、链接成 minios.elf 并跑出实验预期输出。
