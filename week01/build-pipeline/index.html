看具体代码：make 到底做了什么？

从 `kernel/main.c` 的 Hello 字符串开始，追到 QEMU 最后加载的 ELF。

kernel/main.c C 源码 
const char *msg = "Hello miniOS on LoongArch64\n";
printk(msg);

这一步生成什么？

kernel/main.c
→
build/kernel/main.o
$(BUILD_DIR)/%.o: %.c
	$(CC) $(CFLAGS) -Iinclude -c $< -o $@

课堂答案

C 文件里有学生能看懂的 `printk(msg)`，但 CPU 不直接执行 C 文本；它要先变成 LoongArch 机器指令片段。

逐行解释

const char *msg：准备要输出的字符串。
printk(msg)：把字符串交给 miniOS 的串口输出函数。
