## 3. 教学目标

1. 默写并解释 `$zero/$ra/$sp/$a0–$a7/$t0–$t8`  
2. 用「读前值→执行→写后值」描述基础运算/逻辑指令  
3. 翻译简单寄存器表达式，不错误覆盖源  
4. 用本课术语注释 `_start` / `clear_bss` / `regs_alu.S`  
5. 通过串口验收串验证理解  

## 4. 重点与难点

**重点：**

- 寄存器 = 机器自带固定格（收银机分币格/计算器），不是便利贴  
- `$ra` = 续做断点，不是地理来源  
- **教材第 3 章指令分类全覆盖，每类 ≥1 条代表**（加减乘/andi/slt/slli/ext.w.b/st.b/bl·jr·beq/idle；浮点口述）  

**难点：**

- 目的寄存器在左；勿覆盖仍需使用的源  
- `$ra` 与 `$a0`（返回值）混淆  
- 把变量名当成寄存器  

## 5. 课前准备

```bash
# 建议在 Ubuntu
make clean && make && make run
```

期望输出含：

```text
alu_expr(3,5,2) = 6
alu_low8(0x1234) = 0x34
alu_sum2(7,1) = 16
03-regs-alu check done
```

白板准备：寄存器前后值空表（至少 `$a0/$a1/$a2/$t0`）。

## 6. 教学流程（约 90–100 分钟）

| 时段 | 内容 | 建议 |
|---|---|---|
| 0–10' | 开场：第2章+§3.1 地图 | PPT 教材进度 / 地图 |
| 10–20' | **第2章风貌** | 四大类、助记符、寻址、编译概览 |
| 20–35' | **2.1.2 寄存器复习** | 总表、场景、$ra |
| 35–50' | **宽度 + 有/无符号存放** | LA32/64、正负存放、扩展 |
| 50–55' | **§3.1 总览** | 四小节 + 读码五步 |
| 55–85' | **§3.1.1→3.1.4 展开** | 算术→逻辑条件→移位→位操作 走读 |
| 85–92' | Demo `make run` | 验收串 |
| 92–100' | 从简实验 + 收束 | 跑通 + 口头 |
### 6.1 关键提问

1. 收银机分币格会不会撕到钱箱另一边？→ 引出「固定、自带」  
2. 写作业接电话，回来怎么知道做到哪？→ `$ra`  
3. `(3+5)-2` 为什么要 `$t0`？→ 勿覆盖源  

### 6.2 Demo 顺序

1. `lib/regs_alu.S` 三函数逐条讲状态变化  
2. `kernel/main.c` 调用与打印  
3. `make run` 验收  
4. 回看 `bl clear_bss` / `jr $ra`  

### 6.3 评价

- 过程：能否独立 `make run`；表是否自写  
- 结果：验收串真实；`$ra` 口径正确；指令三问能答  

## 7. 板书建议

```text
寄存器 = 机器自带固定格（分币格/计算器）≠ 便利贴
$ra = 续做断点（作业第几题）≠ 从哪间房来；≠ $a0 返回值
指令三问：改谁？用谁？执行后？
alu_expr: (3+5)-2=6    alu_low8: 0x1234→0x34    alu_sum2: 16
```
