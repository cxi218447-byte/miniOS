板书要点：
原码：符号位 + 数值位的自然二进制，正负仅差符号位。
反码：正数反码 = 原码；负数反码 = 符号位不变，数值位逐位取反。
补码：正数补码 = 原码；负数补码 = 反码 + 1（末位加 1，向左进位）。
溢出判断：两个加数同号，结果异号 → 溢出（等价于：符号位的进位 ≠ 最高位向外的进位）。
教材例：0x7fffffff + 0x7fffffff → 0xfffffffe（−2）；本页 8 位对照例 0x7f + 0x7f → 0xfe（−2），结果恰好一致，便于对照记忆。
