指令语义表

指令语义
slt rd, rj, rk有符号小于比较，rd = (rj < rk) ? 1 : 0
maskeqz rd, rj, rk条件赋值，rd = (rk == 0) ? 0 : rj
masknez rd, rj, rk条件赋值，rd = (rk != 0) ? 0 : rj
板书要点：
这四条指令是 LoongArch 上常用的“分支消除”（branchless select）写法：用 slt 把比较结果变成 0/1 的“条件位”， 再用一对 maskeqz / masknez 把 b、c 中“不该选的那个”清成全 0，最后用 or 把两路合并—— 因为任意时刻两路中恰好一路是 0，or 等价于“取那个非零的”，比 beq/bne 分支跳转更省流水线开销。
该写法对正负数都成立：maskeqz/masknez 清零的是寄存器的全部位，不依赖数值符号。
自推练习（课件第45页）：把 b、c 换成 5、3 重新跑一遍，观察哪一步 r4 变 0、哪一步 r12 变 0，理解“选择权”在两条指令间的转移。
