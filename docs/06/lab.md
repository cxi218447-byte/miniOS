## 3. 实验任务

### Task1：函数调用中的寄存器与传参

**约定（LP64D，和讲义一致）**：整数/指针参数从 `$a0` 开始依次排列，返回值放在 `$a0`；`bl` 会把“`bl` 指令的下一条指令地址”写进 `$ra`。

#### 3.1 例子（已填好）

```asm
# int sum3(int a, int b, int c)
sum3:
    add.d   $a0, $a0, $a1
    add.d   $a0, $a0, $a2
    jr      $ra

caller_demo:
    addi.d  $a0, $zero, 10
    addi.d  $a1, $zero, 20
    addi.d  $a2, $zero, 30
    bl      sum3
    # 执行到这一行时，$a0 = ?
```

| 寄存器 | 这段代码里存的是什么 |
|---|---|
| `$a0` | 调用前：参数 `a`（10）；`bl sum3` 返回后：返回值（60） |
| `$a1` | 参数 `b`（20），`sum3` 内部不改写它 |
| `$a2` | 参数 `c`（30），`sum3` 内部不改写它 |
| `$ra` | 执行 `bl sum3` 那一刻被写入，值是 `bl sum3` 下一条指令（注释那一行）的地址 |

### Task2：叶子函数 vs 非叶子函数

**判断标准**：函数内部有没有 `bl`（调用别的函数）。没有 → 叶子函数，`$ra` 不会被覆盖，不需要保存；有 → 非叶子函数，`bl` 会覆盖 `$ra`，返回前必须先存后取，把它恢复成自己被调用时的原值。

#### 4.1 例子（已填好）

```asm
funcA:
    slli.d  $a0, $a0, 1
    jr      $ra

funcB:
    addi.d  $sp, $sp, -16
    st.d    $ra, $sp, 8
    bl      funcA
    ld.d    $ra, $sp, 8
    addi.d  $sp, $sp, 16
    jr      $ra
```

| 函数名 | 内部是否有 `bl`（调用了谁） | 叶子 / 非叶子 | 是否需要保存 `$ra` | 为什么 |
|---|---|---|---|---|
| `funcA` | 否 | 叶子 | 不需要 | 内部没有 `bl`，`$ra` 全程不会被覆盖 |
| `funcB` | 是（`bl funcA`） | 非叶子 | 需要 | `bl funcA` 会把 `$ra` 改写成指向 `funcA` 的地址，`funcB` 返回前必须恢复成自己被调用时收到的 `$ra`，否则 `jr $ra` 会跳错地方 |
