# 第 4 次课“访存 + 浮点”精修设计

## 目标与边界

第 4 次课用 90 分钟系统讲授教材第 3 章 §3.2 访存指令与第 4 章浮点基础。课程以“内存中的位模式 → 寄存器 → 运算 → 写回内存”为统一主线，使学生能够逐条说明指令的助记符、操作数和状态变化。

第 3 次课材料保持原边界：访存只点到 `st.b`，浮点只口述边界。本次不提前展开第 6 次课的完整栈帧、第 12 次课的异常上下文或第 13 次课的 CSR/中断机制。

## 教学内容设计

### 访存

正文系统覆盖 `ld.b/ld.bu`、`ld.h/ld.hu`、`ld.w/ld.wu`、`ld.d` 以及 `st.b/st.h/st.w/st.d`。每类指令都明确：

1. 助记符表达的动作与宽度；
2. 三个操作数的角色；
3. 有效地址 `GR[rj] + SignExtend(si12)`；
4. 从内存读取的字节数；
5. 加载到 LA64 通用寄存器后的符号扩展或零扩展；
6. store 只取源寄存器低位写回的截断行为。

使用同一组含最高位为 1 的数据，对比 `ld.b/ld.bu`、`ld.h/ld.hu` 和 `ld.w/ld.wu`。用 `.data/.bss`、`$sp + offset` 和 UART MMIO 说明它们共享地址与 load/store 模型，同时指出 MMIO 的副作用和 `volatile` 编译语义。对齐只讲访问宽度对应的自然对齐及未对齐访问的平台风险。

### 浮点

从 IEEE754 binary32/binary64 的符号位、阶码和尾数进入 `$f0–$f31`，说明 `.s/.d` 后缀与 C 的 `float/double`。新增 `fld.s/fld.d` 和 `fst.s/fst.d`，把浮点寄存器与本课前半段的内存模型连接起来。

精讲代表指令 `fadd.s/fadd.d`，并用同一操作数表格说明 `fsub`、`fmul`、`fdiv` 的助记符、操作数和状态变化。介绍浮点比较产生条件结果及后续选择/分支的概念链路，具体指令以当前工具链支持和教材表述为准。

继续保留“搬位模式”与“转换数值”的对比：`movgr2fr`/`movfr2gr` 不重新编码，`ffint`、`ftint`/`ftintrz` 和单/双精度转换会重新编码。明确 `rz` 是向零舍入，并点名默认舍入、NaN、正负无穷、正负零和非规格化数的边界，不把异常处理机制提前展开。

裸机运行前设置 `CSR.EUEN.FPE`。本次只讲“未使能会触发指令未使能异常”和 `csrwr` 的可见状态变化。

## 代码与实验闭环

`lib/mem_fp.S` 新增两组可运行示例：

- 半字和字的有/无符号加载，返回可由串口打印的 64 位结果；
- 从内存用 `fld` 加载两个浮点数，经浮点运算后用 `fst` 写回第三个位置。

`include/mem_fp.h` 提供对应 C 接口，`kernel/main.c` 构造固定输入并打印确定性结果。验收先要求学生预测寄存器或内存状态，再运行 QEMU 核对。实验不要求学生实现完整浮点格式化输出，继续通过 IEEE754 位模式和必要的整数转换展示结果。

## 验收标准

1. 讲义正文而非仅附录覆盖 `ld/st` 宽度、加载扩展和写入截断。
2. 浮点部分包含 `fld/fst`，形成内存—FPR—运算—内存闭环。
3. 学生能区分搬位、数值转换和浮点运算。
4. PPT 同时覆盖访存和浮点，末页正确指向第 5 次课，字号全部不低于 24 磅。
5. 示例能够用课程规定的 LoongArch 交叉工具链编译，并在 QEMU 中产生与资料一致的串口输出。
6. 全部资料只使用“第 N 次课”的称法。
