# 第 1 周课程压缩为单次 90 分钟课设计

## 背景

本设计取代 `docs/superpowers/specs/2026-07-24-week01-lesson1-2-expansion-design.md`（该文档假设第 1 周分两次 90 分钟连堂课，尝试给第 1+2 节"扩容"）。实际教学安排发生变化：

- 第 1 周原来的"四节课"内容（为什么学习汇编 / LoongArch 最小知识包 / 从 C 到可执行文件 / QEMU Hello miniOS 实验）要压缩进**一次 90 分钟课**。
- 原计划的"第 2 次课"改为提前进入第 2 周内容（`.data`/`.bss`），不在本次范围内，后续单独立项。
- 用户明确要求：这是"整理压缩"，不是"扩容"——删除真正冗余的内容，合并可以合并的内容，而不是新造练习/小测/虚构示例来填时间。
- 压缩过程中发现三个学生缺失的背景知识，需要补充：操作系统平时做什么、裸机启动的完整流程、Makefile 基本写法。这三块是真实的知识缺口，不是凑时长，因此仍然要加，同时从别处删减以保持 90 分钟总量不变。

## 目标

把 `scripts/generate_week01_course_ppt.py` 中第 1 周部分从 31 张幻灯片（4 个章节过渡页 + 27 张内容片）压缩、重组为 21 张，塞进一次 90 分钟课；同步重写 `docs/week01/week01_qemu_hello_lecture_notes.md`，不再按"第 1-4 节"分节，改为按新的板块结构组织。

## 内容取舍

### 删除（内容冗余，直接去掉，不迁移到别处）

- 4 张章节过渡页（原每节一张"第 X 节"大标题页）——单次课不需要 4 次全屏转场，用小标签替代。
- "第一节课堂活动"——与开场导入问题完全重复。
- "第二节学习目标"——4 条目标性陈述，后续内容已经覆盖，删除不影响教学。
- "本周课程结构"——Why/Demo/Do/AI/思考的抽象框架回顾，和 AGENTS.md 重复，不是学生必须在课堂上看到的内容。
- "第二节练习"——课堂口头提问即可，不需要单独占一张幻灯片。

### 合并（内容保留，但不再单独占一张）

- "源码写法和教材写法如何对应" → 并入"基础指令例子"幻灯片的副标题（一句话点出 `$sp` 等价 `r3`）。
- "预期输出与测试记录"（含反幻觉记录要求）→ 并入"实验命令"幻灯片的副标题。
- "当前 master 比第 1 周略多" + "本周边界" → 合并为一张"本周边界"。
- "AI 共学边界" → 并入合并后的"本周边界"，作为其中一条。
- "第一周学生作业" → 并入"思考题"，合并为一张"思考题与作业"。

### 新增/升级（真实知识缺口，不是凑时长）

- **操作系统平时帮你做了什么**（新增 bullet 幻灯片）：说明普通 C 程序"写完就能跑"背后有 OS 在准备环境（加载、栈堆、进程调度、系统调用、设备抽象），为后面"裸机程序没有这些"做铺垫。
- **Makefile 语法速览**（新增 code 幻灯片，通用最小示例，非本项目代码）：目标/依赖/命令三段式、Tab 缩进、`:=`/`?=` 变量赋值、`.PHONY`。放在本项目 Makefile 变量说明之前，作为语法基础。
- **boot/start.S 主路径逐行讲解**（升级）：把原来的纯代码幻灯片换成 `add_code_annotated_slide`（复用 Task 1 已经写好的通用组件），左侧放本项目真实代码，右侧逐行编号说明——用的是仓库里已有的真实代码，不是虚构编译输出，不违反反幻觉口径。
- **裸机启动逐步说明**（新增 bullet 幻灯片，8 步）：配合已有的"最小运行链路"流程图，给出从 QEMU 加载 ELF 到终端显示 Hello 的文字版逐步说明。

## 架构

沿用 `scripts/generate_week01_course_ppt.py` 现有的 python-pptx builder 模式，复用 Task 1 已经写好的 `add_table_slide`（通用表格）、`add_code_annotated_slide`（左代码右注解）。本次不再新增 builder 函数，只重写 `build()` 函数中第 1 周对应的部分。

## 讲义同步

`docs/week01/week01_qemu_hello_lecture_notes.md` 需要从"第 4 节：从 C 到 ELF"式的四节分节结构，改写为按上述五个板块组织，删除/合并的内容在讲义里也同步删除/合并，新增的三块内容（操作系统做什么、Makefile 语法速览、裸机启动逐步说明）在讲义里写出对应的教师讲解要点。原讲义里 4.4/4.5/5.5/5.6/5.7（若在此之前已经写入，来自上一版设计）需要一并清理，不能和新结构并存造成冲突。

## 验证方式

1. 运行 `python scripts/generate_week01_course_ppt.py`，确认第 1 周部分幻灯片数量为 21（加上全局其他周次内容，总数以脚本实际打印为准）。
2. 用 `PYTHONIOENCODING=utf-8 python -c "..."` 方式导出文字（Windows 控制台默认编码不是 UTF-8，直接 `python -c` 会导致校验乱码误判，必须显式设置该环境变量），确认新增内容字符串存在、已删除内容字符串不存在。
3. 确认 `docs/week01/week01_qemu_hello_lecture_notes.md` 不再包含"第 1 节"/"第 2 节"/"第 3 节"/"第 4 节"这种旧分节标题。
