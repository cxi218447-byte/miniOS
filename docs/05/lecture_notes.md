## 4. 课程知识

### 4.1 控制流指令家族

| 指令 | 含义 | C 直觉 |
|---|---|---|
| `b L` | 无条件转到 L | `goto L` |
| `beq rs, rt, L` | 相等则转 | `if (rs==rt) goto L` |
| `bne rs, rt, L` | 不等则转 | `if (rs!=rt) goto L` |
| `beqz rs, L` | 为 0 则转 | `if (rs==0) goto L` |
| `bnez rs, L` | 非 0 则转 | `if (rs!=0) goto L` |

### 4.2 局部标号 `1b` / `2f`

- `1b`：向后找数字标号 1（back）  
- `2f`：向前找数字标号 2（forward）  
便于写短循环，避免想名字。

### 4.3 结构化模板

#### 汇编精讲：while 计数

```asm
# $a0 = n，执行 n 次 body
loop:
    beqz    $a0, done
    # ... body ...
    addi.d  $a0, $a0, -1
    b       loop
done:
```

1. **先判空**：`n==0` 直接结束。  
2. **体**与**步进**分离。  
3. **`b loop`** 回到条件。  

#### 汇编精讲：if-else

```asm
    beqz    $a0, else_part
    # then
    b       endif
else_part:
    # else
endif:
```

强调：then 结束要跳过 else，否则两路都执行。

#### 汇编精讲：字符串遍历

```asm
# $a0 指向 C 字符串
1:
    ld.bu   $t0, $a0, 0
    beqz    $t0, 2f
    # 可在此处理 $t0 字符
    addi.d  $a0, $a0, 1
    b       1b
2:
```

1. 读字节 → 判 `'\0'` → 处理 → 指针++ → 回跳。  
2. 这是 `strlen`、`uart_puts` 的共同骨架。  

#### 汇编精讲：回看 clear_bss

```asm
1:
    beq         $t0, $t1, 2f
    st.b        $zero, $t0, 0
    addi.d      $t0, $t0, 1
    b           1b
2:
```

对照 while：条件是“游标未到终点”，体是“写 0”，步进是“地址+1”。

### 4.4 完整走一遍 miniOS 代码链路：以数组查找为例（第 4 学时核心）

**这一步的目的不是"现场编出一个新函数"，而是把"改一个功能要动仓库里哪几个地方、
改完怎么编译运行"这条完整链路讲透**：声明接口（`.h`）→ 写实现（`.S`）→ 接入调
用点（`.c`）→ 编译（`make`）→ 运行核对（`qemu`）。5.2 的独立任务要求学生自己走
完全同样的链路，所以这里必须先示范到位。`bl_find_first` 本身的代码直接给出，
重点放在"链路怎么串起来"而不是"现场推导"。

**题目**：写一个函数，输入是一个 `long` 数组的首地址、长度和目标值，返回目标值第一次
出现的下标；如果数组里没有这个值，返回 -1。

**五问打底（边问边板书）**：

1. **输入**：`$a0` = 数组首地址，`$a1` = 长度，`$a2` = 目标值。
2. **输出**：找到的下标（或 -1）最终写回 `$a0`。
3. **临时寄存器**：遍历指针、下标、当前元素——`$t0`–`$t2`。
4. **循环不变量**：每轮循环开始前，`base[0..i-1]` 里都还没有出现过目标值。
5. **终止条件**：两个出口——下标扫到 `len` 还没找到（返回 -1），或者中途找到就
   **提前退出**（这是本例的新东西：不是每次都把循环走完）。

**流程图 → 伪代码**：

```text
i = 0
while (i != len):
    if (base[i] == target):
        return i          # 提前退出，不用等循环自然结束
    i = i + 1
return -1                 # 扫完都没找到
```

**关键新模式：“提前退出”**——之前的 while 模板（`clear_bss`、`bl_sum1n`、`bl_count_nonzero`）
都是老老实实把整个范围走一遍才结束；这里一旦满足条件就直接 `jr $ra` 返回，不再回到
循环头部。要强调：提前退出本身不是新指令，只是把"返回"这个动作提前搬到了循环体
中间，而不是等在循环外面。

**汇编精讲：`bl_find_first`**

```asm
# $a0 = base, $a1 = len, $a2 = target；找到返回下标，没找到返回 -1，结果从 $a0 返回
bl_find_first:
    move    $t0, $a0           # t0 = 遍历指针，从 base 开始
    addi.d  $t1, $zero, 0      # t1 = i = 0

1:
    beq     $t1, $a1, 3f       # 条件：i==len，扫完了还没找到 -> 3
    ld.d    $t2, $t0, 0        # t2 = base[i]
    beq     $t2, $a2, 2f       # 找到 -> 提前退出到 2（不回 1b）
    addi.d  $t0, $t0, 8        # 指针前进到 base[i+1]（long 占 8 字节）
    addi.d  $t1, $t1, 1        # 步进：i++
    b       1b                 # 回跳

2:
    move    $a0, $t1           # 找到：返回下标
    jr      $ra

3:
    addi.d  $a0, $zero, -1     # 没找到：返回 -1
    jr      $ra
```

课堂节奏建议：不要求学生现场推导，直接展示代码，重点讲"这行为什么这样写"；刻意
问学生"如果把 `beq $t2, $a2, 2f` 这一行删掉会怎样"（循环会扫完整个数组，但永远
走不到提前退出的分支，退化成普通遍历），检验是否真的理解"提前退出"这个结构，而
不是死记指令顺序。真正要求学生自己动脑的是 5.2 独立实现的 `bl_find_last`。

这段代码**不预先提交进仓库**——由学生自己在第 4 学时敲进
`lib/branch_loop.S`/`include/branch_loop.h`/`kernel/main.c`（步骤见
`docs/05/lab.md` §5.1），`make run` 后串口应输出：

```text
loop  find_first {3,7,3,9,3,2} target=3 = 0
loop  find_first {3,7,3,9,3,2} target=99 = -1
```

（已实测跑通：target=3 时第一次出现在下标 0；target=99 数组里没有，返回 -1。）

### 4.5 汇编程序设计方法（本课核心方法论）

写程序前强制五问：

1. **输入**在哪些寄存器/内存？  
2. **输出**写到哪里？  
3. **哪些寄存器**可作临时？会不会破坏仍需的值？  
4. **循环不变量**是什么？（例如：`$t0` 始终指向下一个待清零字节）  
5. **是否必然终止**？游标/计数是否更新？

推荐流程：

```text
自然语言 → 流程图 → 伪代码 → 汇编 → 寄存器模拟走两遍 → 再上机
```

## 9. 板书
