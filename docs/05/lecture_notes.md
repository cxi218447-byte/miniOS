## 4. 课程知识

### 4.1 控制流指令家族

| 指令 | 含义 | C 直觉 |
|---|---|---|
| `b L` | 无条件转到 L | `goto L` |
| `beq rs, rt, L` | 相等则转 | `if (rs==rt) goto L` |
| `bne rs, rt, L` | 不等则转 | `if (rs!=rt) goto L` |
| `beqz rs, L` | 为 0 则转 | `if (rs==0) goto L` |
| `bnez rs, L` | 非 0 则转 | `if (rs!=0) goto L` |

### 4.2 局部标号 `1b` / `2f`

- `1b`：向后找数字标号 1（back）  
- `2f`：向前找数字标号 2（forward）  
便于写短循环，避免想名字。

### 4.3 结构化模板

#### 汇编精讲：while 计数

```asm
# $a0 = n，执行 n 次 body
loop:
    beqz    $a0, done
    # ... body ...
    addi.d  $a0, $a0, -1
    b       loop
done:
```

1. **先判空**：`n==0` 直接结束。  
2. **体**与**步进**分离。  
3. **`b loop`** 回到条件。  

#### 汇编精讲：if-else

```asm
    beqz    $a0, else_part
    # then
    b       endif
else_part:
    # else
endif:
```

强调：then 结束要跳过 else，否则两路都执行。

#### 汇编精讲：字符串遍历

```asm
# $a0 指向 C 字符串
1:
    ld.bu   $t0, $a0, 0
    beqz    $t0, 2f
    # 可在此处理 $t0 字符
    addi.d  $a0, $a0, 1
    b       1b
2:
```

1. 读字节 → 判 `'\0'` → 处理 → 指针++ → 回跳。  
2. 这是 `strlen`、`uart_puts` 的共同骨架。  

#### 汇编精讲：回看 clear_bss

```asm
1:
    beq         $t0, $t1, 2f
    st.b        $zero, $t0, 0
    addi.d      $t0, $t0, 1
    b           1b
2:
```

对照 while：条件是“游标未到终点”，体是“写 0”，步进是“地址+1”。

### 4.4 汇编程序设计方法（本课核心方法论）

写程序前强制五问：

1. **输入**在哪些寄存器/内存？  
2. **输出**写到哪里？  
3. **哪些寄存器**可作临时？会不会破坏仍需的值？  
4. **循环不变量**是什么？（例如：`$t0` 始终指向下一个待清零字节）  
5. **是否必然终止**？游标/计数是否更新？

推荐流程：

```text
自然语言 → 流程图 → 伪代码 → 汇编 → 寄存器模拟走两遍 → 再上机
```
