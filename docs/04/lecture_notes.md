## 2. 从“数据放在哪里”开始

| 位置 | 特点 | 例子 |
|---|---|---|
| 寄存器 | 数量少、速度快，算术指令直接使用 | `$t0` 中的地址、`$fa0` 中的浮点参数 |
| 内存 | 容量大，必须经 load/store 与寄存器交换 | 数组、全局变量、栈槽 |
| MMIO | 使用内存地址和访存指令，但访问会产生设备副作用 | UART 数据寄存器 |

教学用地址空间：

```text
高地址
  栈（$sp 通常向低地址增长）
  ...
  .bss       未显式存储初值，启动时清零
  .data      有初值的可写数据
  .rodata    只读常量
  .text      指令
低地址
```

第 2 次课的段是统一地址空间中的不同区域，不是互不相干的“盒子”。

## 3. 寻址方式与有效地址

课件列出了立即、寄存器、直接、寄存器间接、基址/变址和 PC 相对等常见寻址方式。本次课的核心是：

```text
有效地址 EA = GR[rj] + SignExtend(si12)
```

例如，若 `$sp = 0x9000`：

```asm
ld.d    $t1, $sp, 16
```

- **助记符**：`ld.d`，从内存加载 8 字节。
- **操作数**：`$t1` 是目的寄存器，`$sp` 是基址，`16` 是 12 位有符号立即数偏移。
- **状态变化**：有效地址为 `0x9010`；内存 `[0x9010, 0x9017]` 的 8 字节进入 `$t1`；内存和 `$sp` 不变。

### 三组普通访存寻址

| 形式 | 示例 | 有效地址 | 用途 |
|---|---|---|---|
| 立即数偏移 | `ld.d $t0,$t1,8` | `GR[t1] + SignExtend(si12)` | 字段、栈槽、固定下标 |
| 寄存器变址 | `ldx.w $t0,$t1,$t2` | `GR[t1] + GR[t2]` | 运行时数组下标 |
| 对齐远偏移 | `stptr.d $t0,$t1,100` | `GR[t1] + SignExtend(si14) × 4` | 更大范围的对齐访问 |

`ldptr/stptr` 的偏移经过缩放。讲解时必须把“汇编写出的立即数”和“实际字节偏移”分开，避免把示例中的 `100` 误解为 100 字节。

## 4. 普通 `ld/st`：宽度、扩展与截断

### 4.1 加载家族

| 指令 | 读取宽度 | 写入 LA64 通用寄存器时的处理 |
|---|---:|---|
| `ld.b` / `ld.bu` | 1 字节 | 符号扩展 / 零扩展 |
| `ld.h` / `ld.hu` | 2 字节 | 符号扩展 / 零扩展 |
| `ld.w` / `ld.wu` | 4 字节 | 符号扩展 / 零扩展 |
| `ld.d` | 8 字节 | 64 位全部写入，无需扩展 |

用内存字节 `0x80` 对比：

```asm
ld.b    $t1, $t0, 0      # $t1 = 0xffffffffffffff80（-128）
ld.bu   $t2, $t0, 0      # $t2 = 0x0000000000000080（128）
```

两条指令访问同一个地址、读取同一个字节，差别只在写回寄存器前如何扩展。字符串按字节处理时通常选 `ld.bu`。

### 4.2 存储家族

| 指令 | 写入宽度 | 源寄存器参与写入的部分 |
|---|---:|---|
| `st.b` | 1 字节 | 最低 8 位 |
| `st.h` | 2 字节 | 最低 16 位 |
| `st.w` | 4 字节 | 最低 32 位 |
| `st.d` | 8 字节 | 全部 64 位 |

```asm
st.b    $t2, $t0, 1
```

- **助记符**：`st.b`，向内存存储 1 字节。
- **操作数**：`$t2` 是数据源，`$t0` 是基址，`1` 是偏移。
- **状态变化**：仅 `Mem[GR[t0]+1]` 被 `$t2` 的低 8 位覆盖；两个寄存器不变，相邻字节不变。

store 不做“有符号/无符号扩展”；它只截取源寄存器低位。因此没有 `st.bu`、`st.hu`、`st.wu`。

### 4.3 回看 `clear_bss`

```asm
1:
    beq       $t0, $t1, 2f
    st.b      $zero, $t0, 0
    addi.d    $t0, $t0, 1
    b         1b
2:
```

- `$t0` 是当前游标地址，`$t1` 是结束地址。
- `st.b` 把当前字节变为 0。
- `addi.d` 令游标加 1；循环覆盖半开区间 `[bss_start, bss_end)`。
- `beq`/`b` 在此只按已有代码读懂；分支编码和程序设计留到第 5 次课。

### 4.4 对齐

- 2/4/8 字节访问通常分别按 2/4/8 字节自然对齐。
- 未对齐访问可能变慢或触发地址对齐例外，具体由平台决定。
- 链接脚本 `ALIGN(4K)` 是段布局的更大粒度对齐，不等同于每条访存的自然对齐要求。

### 4.5 MMIO：设备也是地址

```c
*(volatile unsigned char *)UART0_BASE = ch;
```

对应的汇编核心动作：

```asm
# $t0 = UART0_BASE, $a0 = ch
st.b    $a0, $t0, 0
```

有效地址计算和普通内存相同，但写入会启动设备动作。`volatile` 约束编译器保留并按程序顺序表达设备访问；硬件层面的跨核/设备顺序还可能需要体系结构规定的栅障。

## 5. 访存体系扩展：安全、原子性与顺序

本节对应课件第 18–50 页。目标是识别问题和机制，不要求学生在当前单核实验中实现同步原语。

### 5.1 边界检查访存

课件用 `LDGT/STGT` 和 `LDLE/STLE` 说明“先比较边界，再决定访存；条件不满足则产生边界检查例外”。课堂应强调：它们不是普通 `ld/st` 的默认行为，普通访存不会自动替软件检查数组边界。

异常入口与上下文保存留到第 12 次课，本次只认识“条件失败会进入例外处理”这一边界。

### 5.2 为什么 `a = a + 1` 不是原子的

```asm
ld.w      $t0, $a0, 0
addi.w    $t1, $t0, 1
st.w      $t1, $a0, 0
```

三个独立状态变化是“读内存→寄存器运算→写内存”。两个执行者都读到旧值 3 时，可能都写回 4，最终丢失一次更新。

### 5.3 LL/SC：检测冲突并重试

```asm
retry:
    ll.w      $t0, $a0, 0
    addi.w    $t1, $t0, 1
    sc.w      $t1, $a0, 0
    beqz      $t1, retry
```

- `ll.w`：加载并建立链接监视。
- `addi.w`：只改变寄存器中的候选新值。
- `sc.w`：链接仍有效才写回；目的寄存器随后保存成功/失败状态。
- `beqz`：失败则重新读取最新值并重试。

注意：示例中用作 `sc.w` 源/结果的寄存器会被成功标志覆盖，不要在循环外把它误当作加法结果继续使用。

### 5.4 AM 指令族

`amswap`、`amadd`、`amand`、`amxor`、`ammax`、`ammin` 等把常见读—改—写封装成单条原子操作；`.w/.d` 表示宽度，部分指令有无符号变体，`_db` 变体附带数据屏障语义。这里只建立分类，精确可见性和内存模型不作为本次实验要求。

### 5.5 `DBAR` 与 `IBAR`

- `dbar hint`：约束栅障前后的数据访存顺序。
- `ibar hint`：让代码修改等效果在后续取指时正确可见。

用“先写数据，再发布就绪标志”理解 `DBAR`：原子性回答“一个读改写是否不可分割”，顺序性回答“两个不同访问能否被观察为颠倒”，二者不是一回事。课件用 `hint=0` 演示强数据栅障；具体 hint 语义以所用 LoongArch 手册和处理器实现为准。

## 6. 浮点数表示与寄存器

### 6.1 IEEE 754 binary32 / binary64

| 格式 | 符号 S | 阶码 E | 尾数 F | 偏置 | C 类型 |
|---|---:|---:|---:|---:|---|
| binary32 | 1 位 | 8 位 | 23 位 | 127 | `float` |
| binary64 | 1 位 | 11 位 | 52 位 | 1023 | `double` |

规格化数：

```text
(-1)^S × 2^(E-bias) × 1.F
```

以 `5.75` 为例：`101.11₂ = 1.0111₂ × 2²`，binary32 的 `S=0`、`E=129=10000001₂`、`F=0111000...`。

阶码全 0 或全 1 表示零、非规格化数、无穷或 NaN 等特殊情况。本次要求学生能识别分类，不展开异常标志与完整舍入证明。

### 6.2 浮点寄存器与精度后缀

LoongArch 有 32 个浮点寄存器 `$f0`–`$f31`。在本课使用的 LP64D ABI 中，`$fa0`–`$fa7` 用于浮点参数/返回值，`$ft*` 为临时寄存器，`$fs*` 为需按约定保存的寄存器。

| 后缀 | 含义 | 位宽 |
|---|---|---:|
| `.s` | single | 32 位 |
| `.d` | double | 64 位 |

整数指令的 `.w/.d` 主要指定整数操作宽度；浮点指令的 `.s/.d` 同时指定 IEEE 754 数据格式，不能只理解为“取低几位”。

## 7. 浮点指令体系

### 7.1 浮点访存：形成闭环

```asm
fld.d    $ft0, $a0, 0
fld.d    $ft1, $a0, 8
fadd.d   $ft2, $ft0, $ft1
fst.d    $ft2, $a0, 16
```

逐条状态链：

1. 两条 `fld.d` 分别从普通内存读取 8 字节位模式到 FPR。
2. `fadd.d` 按 binary64 解释两个源寄存器并计算，结果写入 `$ft2`。
3. `fst.d` 把 `$ft2` 的 64 位结果写回内存；它本身不做加法也不改变格式。

`fld/fst` 使用基址+立即数偏移；`fldx/fstx` 使用基址+寄存器变址。它们与整数访存共享地址生成思想，但目的/源是浮点寄存器。

### 7.2 基本运算

| 指令族 | 状态变化 |
|---|---|
| `fadd.s/d fd,fj,fk` | `FPR[fd] = FPR[fj] + FPR[fk]` |
| `fsub.s/d` | 浮点减法 |
| `fmul.s/d` / `fdiv.s/d` | 浮点乘法 / 除法 |
| `fsqrt.s/d` | 平方根 |
| `fabs` / `fneg` | 绝对值 / 改变符号 |
| `fmadd` / `fmsub` | 融合乘加 / 乘减，只进行一次最终舍入 |

代表指令：

```asm
fadd.s   $fa0, $fa0, $fa1
```

- **助记符**：单精度浮点加法。
- **操作数**：左侧为目的 FPR，后两项为源 FPR。
- **状态变化**：按 binary32 解释两个源值，相加并按浮点规则舍入到 `$fa0`；通用寄存器与内存不变。

### 7.3 比较与分支

```asm
fcmp.slt.s   $fcc0, $fa0, $fa1
bcnez        $fcc0, less_path
```

`fcmp.cond.s/d` 把真假结果写入 `$fcc0`–`$fcc7` 之一；`bceqz/bcnez` 再读取条件标志决定是否转移。比较与跳转是两个状态步骤。NaN 参与比较时必须遵循所选 `cond` 的有序/无序语义，不能直接套整数比较直觉。

转移指令的偏移、程序结构和循环设计留到第 5 次课。

### 7.4 搬位模式与转换数值

| 指令 | 是否重新编码 | 作用 |
|---|---|---|
| `movgr2fr.w` / `movfr2gr.s` | 否 | 在 GPR 与 FPR 之间搬运位模式 |
| `fcvt.s.d` / `fcvt.d.s` | 是 | 单精度与双精度互转 |
| `ffint.s/d.w/l` | 是 | 整数数值转浮点数值 |
| `ftintr*.w/l.s/d` | 是 | 浮点数值按指定规则转整数数值 |
| `frint.s/d` | 是 | 按当前舍入模式取整，结果仍是浮点格式 |

```asm
movgr2fr.w    $fa0, $a0
ffint.d.w     $fa0, $fa0
```

第一条只搬 32 位整数编码；第二条才把该整数数值重新编码成 double。反向的 `ftintrz.w.d` 中，`rz` 表示向零舍入。

### 7.5 裸机使用前提

复位后浮点单元可能未使能。当前示例在 `kernel_main` 开头设置 `CSR.EUEN.FPE`：

```c
unsigned long euen = 1;
__asm__ volatile("csrwr %0, 0x2" : "+r"(euen));
```

`csrwr rd, csr` 把 `rd` 写入 CSR，并把 CSR 的旧值写回 `rd`。本课只观察“浮点执行被使能”的结果；未使能引发的指令未使能例外及其上下文留到第 12 次课。

## 10. 板书建议

```text
EA = base + offset
ld*: Mem → GPR；st*: GPR低位 → Mem
ld.b  符号扩展；ld.bu 零扩展
clear_bss = 游标 + st.b 0
UART = 固定地址 + store + 设备副作用

普通读改写 ≠ 原子；LL/SC = 监视 + 条件写 + 重试
DBAR 管数据访存顺序；IBAR 管后续取指可见性

IEEE754: S | E | F
fld/fst: Mem ↔ FPR
fadd.s/d: FPR 运算
mov*: 搬位；ffint/ftint/fcvt: 转换数值
```
